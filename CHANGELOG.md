# Changelog

## V0.1.0 — 2026-10-13

- First local release of the renamed `codex-dosage` project, based on `tollenceld/codex-usage-status` (MIT).
- Use the user-approved terminal-and-usage icon; retain `assets/logo.svg` as its editable source.
- Include automatic/manual application discovery, Chinese/English settings, compact usage panel, reset-card details and credit balances.
- Keep taller Settings/Refresh buttons and the `MM/dd HH:mm:ss` update time.
- Preserve the bundle identifier and existing preferences. Bundle the original MIT license in the application.

Earlier local development versions are recorded in [development history](docs/development-history.md); their 0.2.x versions precede the independent Codex Dosage V0.1.0 release.
